# module5_honeypot

Flags provably-impossible profiles, which module6 then forces to a score of 0.

- **H1** — 3 or more skills at advanced/expert with `duration_months == 0`
- **H2** — total career months > `years_of_experience * 12 * 1.5 + 12`

These fire on ~0.043% of the pool. A keyword-stuffer with the wrong title is *not*
a honeypot — module2 and the anti-signals sink that on their own; this is reserved
for genuinely impossible profiles.
